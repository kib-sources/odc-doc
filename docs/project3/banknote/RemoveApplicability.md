# Удаление применимости (OdcbBlockRemoveApplicability)


В **[прошлой главе](SetApplicability.md)**
мы расписали как установить блок применимости.

В этой расскажем как его снять.

:::warning[замечание]
Если на банкноте есть хотя бы один блок применимости,
то она не может быть отправлена в offline
режим без снятия всех блоков применимости.

В offline режиме взаимодействия все блоки применимости 
должны быть сняты.
:::



## Поля

Поля заголовка в `v3` версии протокола:

| Наименование поля           | Описание                                                                      | Пример значения                                  |
|-----------------------------|-------------------------------------------------------------------------------|--------------------------------------------------|
| `bank_id`                   | Уникальный идентификатор банка-эмитента                                       | `Test bank`                                      |
| `banknote_id`               | Уникальный UUID банкноты                                                      | `280bdff8-a345-4854-a60b-b57251ec4d0e`           |
| `parent_hash`               | Ссылка на `hash` предыдущего блока                                            |
| `applicability_uuid`        | Уникальный UUID, совпадает с `applicability_uuid` блока, который нужно снять  |
| `applicability_remove_text` | Текстовое поле, соедражщее информацию о применимости (ссмылки на нормативные документы, законы и т.д.) |                                                                            |
| `comment`                   | (опционально) Дополнительное текстовое поле, не несущее юридическую нагрузку. |
| `salt`                      | Соль. Указывается банком-эмитентом произвольным образом.                      |                                          |
| `pok`                       | открытый ключ процессинга, которым подписывается данный блок `bank_sign`      |
| `hash`                      | Основной хеш блока. Новый блок по `parent_hash` будут указывать на этот хеш   |                                           |
| `bank_sign`                 | Подпись банка эмитента неким привятным ключём `bpk`. Ключ проверки -- `bok`   |                                           |

Блок **OdcbBlockRemoveApplicability**
связывается с блоком **OdcbBlockSetApplicability**
через поле `applicability_uuid`.

Данное поле показывает какой блок отменяется.

Поле `applicability_remove_text`
указывает причину снятия блока.
Содержит юридически значимый текст.
