# Установка применимости (OdcbBlockSetApplicability)

Если банкнота находится в онлайн-режиме,
то к ней можно поставить применимость
(блоком 
**OdcbBlockSetApplicability**
)
или убрать её
(блоком 
**[OdcbRemoveApplicability](RemoveApplicability.md)**
)

:::warning[замечание]
Если на банкноте есть хотя бы один блок применимости,
то она не может быть отправлена в offline 
режим без снятия всех блоков применимости.

В offline режиме взаимодействия все блоки применимости
должны быть сняты.
:::

Блок применимоти позволяет ограничить применение
банкноты.


## Поля

Поля заголовка в `v3` версии протокола:

| Наименование поля        | Описание                                                                                               | Пример значения                                  |
|--------------------------|--------------------------------------------------------------------------------------------------------|--------------------------------------------------|
| `bank_id`                | Уникальный идентификатор банка-эмитента                                                                | `Test bank`                                      |
| `banknote_id`            | Уникальный UUID банкноты                                                                               | `280bdff8-a345-4854-a60b-b57251ec4d0e`           |
| `parent_hash`            | Ссылка на `hash` предыдущего блока                                                                     |
| `applicability_uuid`     | Уникальный UUID (для последующего снятия)                                                              | 
| `applicability_set_text` | Текстовое поле, соедражщее информацию о применимости (ссмылки на нормативные документы, законы и т.д.) |
| `comment`                | (опционально) Дополнительное текстовое поле, не несущее юридическую нагрузку.                          |
| `salt`                   | Соль. Указывается банком-эмитентом произвольным образом.                                               |                                          |
| `pok`                    | открытый ключ процессинга, которым подписывается данный блок `bank_sign`                                |
| `hash`                   | Основной хеш блока. Новый блок по `parent_hash` будут указывать на этот хеш                            |                                           |
| `bank_sign`              | Подпись банка эмитента неким привятным ключём `bpk`. Ключ проверки -- `bok`                            |                                           |


Содержимое полей  `applicability_set_text` и
`comment` по протоколу ODCv3
произвольно. Это текстовые поля.

Однако протокол требует, чтобы 
поле `applicability_set_text` носило формальный характер,
не имело ошибок и помарок, так как его содержимое
является юридически значимым.
В этом поле перечисленны ссылки на внутренние документы 
центрального банка и законы той или иной страны.
По содержимому данного блока должно быть понятно 
на какие цели деньги можно тратить, а на какие цели нельзя.

Что касается поля `comment`  то оно необязательно
и опционально. В этом поле могут быть какие-либо не юридичесие
пояснения технического характера или отладочная информация.

Поле `applicability_uuid` должно быть уникальным в рамках
блоков **OdcbBlockSetApplicability** указанной банкноты
`banknote_id`.
